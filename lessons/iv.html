    第 53 节

    ivregress：工具变量与识别诊断

    用 2SLS 处理模拟内生性，检查第一阶段、内生性和过度识别限制。

    基本语法参数与选项理解命令完整示例运行结果常见错误动手练习继续查帮助

    基本语法

    基本语法
    ivregress 2sls 因变量 外生控制变量 (内生变量 = 排除工具变量), vce(robust)
estat firststage
estat endogenous
estat overid

    语法中的中文名称是占位说明；可直接执行的代码见下方完整示例。

    参数与选项

    参数 / 写法作用与使用条件写法示例
    (x = z1 z2)括号内左侧是内生解释变量，右侧是排除工具变量。ivregress 2sls y w (x = z1 z2), vce(robust)
    estat firststage查看工具变量与内生变量的第一阶段相关性诊断。estat firststage
    estat endogenous检验被指定为内生的解释变量是否可以视为外生。estat endogenous
    estat overid工具变量数量多于内生变量数量时才有过度识别限制。estat overid
    liml / gmm其他 IV 估计方法，需结合假设及推断方式选择。ivregress liml y w (x = z1 z2)

    理解命令

    有效工具变量需要与内生变量相关，并在控制其他变量后与结构误差不相关；排除限制还要求它不通过模型之外的渠道直接影响 y。相关性可以诊断，排除限制主要依靠制度背景和研究设计，不能用一项检验完全证明。

    例子让未观测的 u 同时影响 x 和 y，使 OLS 产生偏差；z1、z2 独立生成，只通过 x 进入 y。使用 `ivregress` 一次完成估计，不要手工用第一阶段拟合值再做普通 OLS 并直接解释其标准误。

`estat endogenous` 会按估计时的方差设定使用相应检验，稳健估计后优先使用此命令，而不是机械地 `hausman iv ols`。第一阶段 F 大于 10 是特定情形下的粗略经验，不能当成所有稳健、聚类或多内生变量情形的通行标准。

过度识别检验不拒绝也不等于工具变量有效，弱工具可能让常规推断失真。恰好识别时不能运行有意义的过度识别检验。更高版本的弱工具稳健推断命令需检查本机版本，本节完整示例保持 Stata 17 语法。

    课件对照：Stata basic.pdf，第 9、10、11 页。

    完整示例

    请在 do 文件编辑器中整段运行；示例会准备演示数据，请先保存当前数据。

    iv.do
    clear
set seed 20261018
set obs 1200
generate double z1 = rnormal()
generate double z2 = rnormal()
generate double w = rnormal()
generate double u = rnormal()
generate double x = 1.2*z1 + .9*z2 + .5*w + u + .5*rnormal()
generate double y = 1 + 2*x + .5*w + u + rnormal()
regress y x w, vce(robust)
estimates store ols_iv_demo
ivregress 2sls y w (x = z1 z2), vce(robust)
estimates store iv_demo
estat firststage
estat endogenous
estat overid
estimates table ols_iv_demo iv_demo, b(%9.3f) se(%9.3f) stats(N)

    运行结果

    两种模型均使用 1200 行；IV 的 x 系数接近结构参数 2，OLS 通常偏高。第一阶段显示 z1、z2 的相关性，内生性和过度识别输出对应各自原假设；单次模拟的 p 值不是固定结论。

    常见错误

    • 不能因第一阶段显著就断言排除限制成立。
    • robust 不会把无效工具变为有效，也不能自动解决弱工具问题。
    • 不要把出生季度、距离等变量当成天然有效的工具，必须解释具体背景。

    动手练习

    只用一个工具 z1 为 x 提供工具后，能否做过度识别检验？

    查看参考答案

    一个内生变量与一个排除工具构成恰好识别，没有多余的过度识别限制；不能靠 estat overid 检验工具有效性。
