    异常值与缩尾：先核查，再决定处理

    用四分位距标记极端值，保留原变量并展示百分位缩尾的实现。

    基本语法参数与选项理解命令完整示例运行结果常见错误动手练习继续查帮助

    基本语法

    基本语法
    summarize 变量, detail
generate byte 标记 = (变量 < 下界 | 变量 > 上界) if !missing(变量)
* 已安装 winsor2 时可用：winsor2 变量, cuts(1 99) suffix(_w)

    语法中的中文名称是占位说明；可直接执行的代码见下方完整示例。

    参数与选项

    参数 / 写法作用与使用条件写法示例
    r(p25) / r(p75)detail 返回第一、第三四分位数；IQR 为两者之差。local iqr = r(p75) - r(p25)
    1.5 × IQR常见探索性标记规则，不等于录入错误判据。local hi = r(p75) + 1.5 * `iqr'
    r(p1) / r(p99)1% 与 99% 分位点，属于百分位规则而非 IQR 规则。local p99 = r(p99)
    winsor2用户扩展；缩尾保留行数，截尾则删除观测。winsor2 income, cuts(1 99) suffix(_w)

    理解命令

    极端值可能是录入错误，也可能是真实的高收入。先查来源、单位和重复记录，再标记供复核。IQR 规则用 Q1−1.5×IQR 和 Q3+1.5×IQR；1%/99% 分位规则是另一种方法，不能混称。

    `summarize, detail` 的结果保存在 `r()` 中，下一条返回结果的命令可能覆盖它们，所以先用局部宏保存阈值。比较上下界时排除缺失：Stata 的数值缺失大于所有非缺失数，会被错误地标记为高值。

缩尾把超过阈值的值压到边界，截尾把这些行删除。以下例子用内置命令演示百分位缩尾，不依赖外部包，并用新变量保留原始 price。真实报告应写清阈值、处理数量、经济依据，以及采用原数据时的敏感性结果。

    课件对照：Stata basic.pdf，第 5 页。

    完整示例

    请在 do 文件编辑器中整段运行；示例会准备演示数据，请先保存当前数据。

    outliers.do
    sysuse auto, clear
quietly summarize price, detail
local iqr = r(p75) - r(p25)
local lo = r(p25) - 1.5 * `iqr'
local hi = r(p75) + 1.5 * `iqr'
local p10 = r(p10)
local p90 = r(p90)
generate byte outlier_iqr = (price < `lo' | price > `hi') if !missing(price)
clonevar price_w = price
replace price_w = `p10' if price < `p10' & !missing(price)
replace price_w = `p90' if price > `p90' & !missing(price)
tabulate outlier_iqr
list make price price_w if price != price_w, noobs

    常见错误

    • 只写 income > 上界 会把缺失也标为异常。
    • 不要直接 winsor2 ..., replace 后丢失原始变量；优先生成新变量。
    • 百分位点依赖样本和算法，不能把小样本阈值直接用到其他数据。

    动手练习

    本例对 price 进行缩尾后，原始 price 和行数是否改变？

    查看参考答案

    都不改变。结果写入 price_w，原始 price 保留，仍有 74 条观测。
