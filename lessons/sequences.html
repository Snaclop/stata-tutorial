    第 36 节

    seq 与 fill：生成练习序列

    创建年份循环和分块编号，理解行顺序如何影响结果。

    基本语法参数与选项理解命令完整示例运行后看什么常见错误动手练习继续查帮助

    基本语法

    基本语法
    set obs N
egen x=seq(), from(a) [to(b) block(k)]
egen y=fill(模式)

    语法中的中文名称是占位说明；可直接执行的代码见下方完整示例。

    参数与选项

    参数 / 写法作用与使用条件写法示例
    set obs在空数据或现有数据后设定/增加行数set obs 6
    from()序列起点from(2021)
    to()到达上限后循环；省略时继续递增to(2023)
    block()每个序号连续重复多少行block(3)
    fill()按给定数列模式延展fill(2 4)

    理解命令

    seq() 按当前行位置生成数列，不是从其他变量推断时间或地区。它适合搭建平衡的小型练习数据，也可用于给明确顺序的行赋编号。

    年份循环和分块 id 配合时，可以构造“每个对象三年”的结构。生成后要核对对象与年份组合是否唯一，不要只凭表面排列认定它有正确的数据含义。

    完整示例

    请在 do 文件编辑器中整段运行；示例会准备演示数据，请先保存当前数据。

    sequences.do
    clear
set obs 6
egen year=seq(), from(2021) to(2023)
egen id=seq(), from(1) block(3)
egen even=fill(2 4)
isid id year
list, noobs

    运行后看什么

    year 为 2021、2022、2023 循环两遍；id 为 1、1、1、2、2、2；even 为 2、4、6、8、10、12。

    常见错误

    • 先生成再排序，序列不会自动跟着新顺序重新计算。
    • 人为生成的序列只能当作演示或有依据的编号，不能代替真实观测。

    动手练习

    每个 id 希望连续出现4次，哪个参数要改？

    查看参考答案

    block(4)，同时根据需要调整总行数及年份循环。
