    estimates 与 putexcel：比较和导出回归结果

    保存多个模型，用统一表格比较，并把系数及标准误导出为 Excel。

    基本语法参数与选项理解命令完整示例运行结果常见错误动手练习继续查帮助

    基本语法

    基本语法
    estimates store 模型名
estimates table 模型1 模型2, b(%9.3f) se(%9.3f) stats(N r2)
putexcel set "结果.xlsx", replace
putexcel A1 = "指标" B1 = "估计值"
* 已安装 estout 时：esttab 模型1 模型2 using "结果.rtf", replace se r2

    语法中的中文名称是占位说明；可直接执行的代码见下方完整示例。

    参数与选项

    参数 / 写法作用与使用条件写法示例
    estimates store把当前估计保存在内存中；新回归不会改写该命名结果。estimates store model1
    estimates restore将命名模型恢复为当前估计。estimates restore model2
    b() / se() / stats()控制比较表的系数、标准误和模型统计量。estimates table model1 model2, b(%9.3f) se(%9.3f) stats(N r2)
    putexcelStata 内置输出，不需要安装扩展。putexcel B2 = (_b[education])
    esttab / estout外部包 estout 提供；可以导出 RTF 等格式。esttab model1 model2 using "tutorial_models.rtf", replace se r2

    理解命令

    每次回归都会替换当前 e()；先 estimates store 保存，再运行下一个模型。比较系数时同时报告标准误、样本量、控制变量及方差估计方式。因缺失导致样本变化时，应区分“控制变量改变”与“样本改变”的影响。

    `estimates table` 可以同时显示系数和标准误；若想添加显著性星号，内置该命令的 `star()` 与 `se()` 等统计显示选项存在限制，应按帮助选择表格形式。课件中同时使用这两项的写法不宜直接照抄。论文表格不能用星号替代不确定性和经济意义的解释。

以下示例只用内置命令，将两个模型的教育系数、标准误、N 与 R-squared 写入 Excel。需要 RTF 时可先查看并安装 estout，再按参数表的 esttab 语法导出；它属于用户扩展，不是 Stata 自带功能。

输出前写清变量单位、标准误种类和样本定义。`estimates store` 只保存在当前 Stata 会话；可复现项目仍需保留 do 文件、原始数据来源及运行日志。

    课件对照：Stata basic.pdf，第 9、14 页。

    完整示例

    请在 do 文件编辑器中整段运行；示例会准备演示数据，请先保存当前数据。

    示例会在当前目录生成 tutorial_models.xlsx；再次运行可能覆盖这些同名演示文件。

    model-output.do
    clear
set seed 20261017
set obs 240
generate double education = 8 + 8 * runiform()
generate double experience = 25 * runiform()
generate double wage = 5 + 2 * education + .4 * experience + 3 * rnormal()
regress wage education, vce(robust)
estimates store output1
regress wage education experience, vce(robust)
estimates store output2
estimates table output1 output2, b(%9.3f) se(%9.3f) stats(N r2)
putexcel set "tutorial_models.xlsx", replace
putexcel A1 = "Statistic" B1 = "Model 1" C1 = "Model 2"
putexcel A2 = "Education coefficient" A3 = "Robust SE" A4 = "N" A5 = "R-squared"
estimates restore output1
putexcel B2 = (_b[education]) B3 = (_se[education]) B4 = (e(N)) B5 = (e(r2))
estimates restore output2
putexcel C2 = (_b[education]) C3 = (_se[education]) C4 = (e(N)) C5 = (e(r2))
putexcel A7 = "Simulated data; heteroskedasticity-robust standard errors."
import excel using "tutorial_models.xlsx", sheet("Sheet1") cellrange(A1:C5) firstrow clear
list, noobs

    运行结果

    生成 tutorial_models.xlsx，B 列对应单变量模型、C 列对应加入经验的模型，N 都为 240。代码最后重新读入表格以便检查，内存此时是导出的 4 行指标表，不再是 240 行模拟工资数据。

    常见错误

    • 不要把当前 _b[] 误当成之前保存模型的系数，读取前先 estimates restore。
    • replace 会覆盖同名输出，请在示例目录运行。
    • estimates table 和 esttab 是不同命令，选项不能互相照搬。

    动手练习

    若两个模型的 N 不同，比较表应补充什么说明？

    查看参考答案

    说明每个模型的样本筛选与缺失情况；必要时先固定共同估计样本再重新比较，并报告标准误类型、控制变量和变量单位。
