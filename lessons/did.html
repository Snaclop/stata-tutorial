    Stata 教程/政策评估

    第 54 节

    DID：处理组、对照组与政策前后

    用交互项和双向固定效应估计共同政策时点下的双重差分。

    基本语法参数与选项理解命令完整示例运行结果常见错误动手练习继续查帮助

    基本语法

    基本语法
    generate byte did = treat * post
regress y i.treat##i.post, vce(cluster id)
xtset id year
xtreg y did i.year, fe vce(cluster id)

    语法中的中文名称是占位说明；可直接执行的代码见下方完整示例。

    参数与选项

    参数 / 写法作用与使用条件写法示例
    treat处理组为 1，对照组为 0；本例组别不随时间变。generate byte treat = (id <= 40)
    post政策后为 1；本例所有处理单位同时在 2015 年实施。generate byte post = (year >= 2015)
    i.treat##i.post同时加入组别、时期和交互项。regress y i.treat##i.post, vce(cluster id)
    fe + i.year控制个体和年份固定效应。xtreg y did i.year, fe vce(cluster id)
    reghdfe可扩展到多维固定效应；用户扩展，需先安装。reghdfe y did, absorb(id year) vce(cluster id)

    理解命令

    DID 比较“处理组政策后的变化”减去“对照组同期的变化”。交互项系数才是这两个变化之差，不能把处理组政策前后的一次变化直接解释为政策效应。完整示例包含 80 个单位、6 年，处理组与对照组各 40 个，统一于 2015 年实施政策。

    因果解释依赖平行趋势、无提前反应、对照组未受溢出影响及样本构成可比较等假设。固定效应只能控制相应的不随时间或共同时间因素，不会自动保证这些假设。这里用单位作为政策分配及聚类层级，实际研究应按政策分配和误差相关结构选择。

用 `xtreg ..., fe` 吸收个体效应，再加 `i.year` 控制共同年度冲击，处理组指标和 post 会分别被个体、年份效应吸收。无需再同时指定 robust 与 cluster；`vce(cluster id)` 已给出所需的聚类稳健方差。

本节限于共同实施时点的设计。错位实施且效应随组别、时间变化时，直接使用传统双向固定效应可能混入不合适比较，应改用与设计匹配的分组及时点方法。

    课件对照：Stata basic.pdf，第 11、12 页。

    完整示例

    请在 do 文件编辑器中整段运行；示例会准备演示数据，请先保存当前数据。

    did.do
    clear
set seed 20261019
set obs 80
generate int id = _n
generate byte treat = (id <= 40)
generate double unit_effect = rnormal()
expand 6
bysort id: generate int year = 2011 + _n
generate byte post = (year >= 2015)
generate byte did = treat * post
generate double y = 10 + unit_effect + .5*(year-2012) + 2*did + .5*rnormal()
isid id year
regress y i.treat##i.post, vce(cluster id)
estimates store did_pooled
xtset id year
xtreg y did i.year, fe vce(cluster id)
estimates store did_fe
display "DID estimate = " _b[did]
tabulate treat post
estimates table did_pooled did_fe, b(%9.3f) se(%9.3f) stats(N)

    运行结果

    共 480 行，处理组和对照组在政策前、后各有 120 行。固定效应模型中的 did 系数接近设定的 2。此模拟明确满足相应生成假设，真实数据仍需研究设计和诊断支持。

    常见错误

    • 不能只比较处理组前后均值，忽略对照组的同期变化。
    • 聚类层级应与政策分配相匹配；只有一两个政策组时，常规聚类推断可能不可靠。
    • 处理发生时间不同的样本不能直接照搬本例。

    动手练习

    为什么固定效应回归中没有再单独加入 treat 和 post？

    查看参考答案

    treat 不随个体内时间变化，被个体固定效应吸收；post 是共同年份的函数，被 i.year 吸收。did 仍随处理组及政策后同时变化。
