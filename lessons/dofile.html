    do 文件、注释与续行

    把可以重复执行的命令组织成一个清楚的脚本。

    基本语法参数与选项理解命令完整示例运行后看什么常见错误动手练习继续查帮助

    基本语法

    基本语法
    do "分析.do"
doedit "分析.do"
命令 ///
    后续部分

    语法中的中文名称是占位说明；可直接执行的代码见下方完整示例。

    参数与选项

    参数 / 写法作用与使用条件写法示例
    do执行一个 do 文件do "分析.do"
    doedit用编辑器打开文件，不直接执行doedit "分析.do"
    // 与 /* */写行尾注释与成对的块注释summarize x // 均值等
    ///把下一行连接到当前命令tabstat x, ///
    #delimit ;改用分号结束命令，之后用 #delimit cr 恢复#delimit cr

    理解命令

    普通模式下，一次换行通常结束一条命令。命令太长时用 /// 续行，执行时把整条多行命令选中。注释写解释和判断依据，不必逐字重复命令。

    Windows 的 do 编辑器通常用 Ctrl+D 执行所选部分或全文。选中一段代码运行时，前面定义的局部宏不一定在新执行范围内仍可用，因此依赖的初始化也要一起执行。

    完整示例

    请在 do 文件编辑器中整段运行；示例会准备演示数据，请先保存当前数据。

    dofile.do
    sysuse auto, clear
* 统计三个指标；换行只是为了便于阅读。
tabstat price weight length, ///
    statistics(n mean min max) ///
    columns(statistics) format(%12.2f)

    运行后看什么

    输出一张包含 price、weight 和 length 的统计表，每个指标各占一行。

    常见错误

    • 行尾用 * 不能代替 //；* 通常放在注释行开头。
    • 使用 #delimit ; 后漏写分号，后续多行可能被连成一条错误命令。

    动手练习

    一条长命令换成三行后报“command ... is unrecognized”，可能为什么？

    查看参考答案

    若没有续行符，Stata 会把下一行当成新命令；补齐 /// 或正确使用分号模式。
