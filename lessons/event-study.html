    第 55 节

    事件研究：设定基准期与检查政策前趋势

    构造合法的相对时期变量，以政策前一年为基准做联合检验。

    基本语法参数与选项理解命令完整示例运行结果常见错误动手练习继续查帮助

    基本语法

    基本语法
    generate event_time = year - 政策年份
generate byte lead2 = treat * (event_time == -2)
generate byte lag0 = treat * (event_time == 0)
xtreg y lead变量 lag变量 i.year, fe vce(cluster id)
test lead变量列表

    语法中的中文名称是占位说明；可直接执行的代码见下方完整示例。

    参数与选项

    参数 / 写法作用与使用条件写法示例
    event_time相对共同政策时点的时间；0 表示实施当年。generate event_time = year - 2015
    lead3 / lead2使用合法变量名表示政策前三年、前两年。generate byte lead2 = treat*(event_time == -2)
    基准期 -1不加入政策前一年交互项，其他系数相对该年解释。省略 lead1
    test lead3 lead2联合检验政策前系数是否为 0。test lead3 lead2
    lincom lag0报告当期相对基准期的估计及置信区间。lincom lag0

    理解命令

    事件研究将一个总的 did 效应拆成多个相对时期的处理组交互项。本例有相对政策期 −3 到 2，省略 −1 期作为基准。lag0 表示政策当年相对政策前一年的处理组与对照组差异之差。

    Stata 变量名不能包含减号，因此不能在 `forvalues k=-3/3` 中生成 pre-3 这样的名字。用 lead3、lead2 表示负事件期，用 lag0、lag1、lag2 表示当期与后期。政策前一年是 −1，删掉 0 期不等于选择政策前一年为基准。

`test lead3 lead2` 是政策前系数的联合检验。不拒绝只能说明在当前样本和检验能力下未发现相应偏离，不能证明平行趋势成立。还应结合置信区间、制度背景、可能的提前反应及对照组选择。

例子仅适用于统一政策时点。若有更长样本并把尾部合并，应明确两端窗口和省略期；若是错位实施，需要采用能处理组别及时点异质性的方法。

    课件对照：Stata basic.pdf，第 11、12 页。

    完整示例

    请在 do 文件编辑器中整段运行；示例会准备演示数据，请先保存当前数据。

    event-study.do
    clear
set seed 20261019
set obs 80
generate int id = _n
generate byte treat = (id <= 40)
generate double unit_effect = rnormal()
expand 6
bysort id: generate int year = 2011 + _n
generate byte post = (year >= 2015)
generate byte did = treat * post
generate double y = 10 + unit_effect + .5*(year-2012) + 2*did + .5*rnormal()
isid id year
generate int event_time = year - 2015
forvalues k = 2/3 {
    generate byte lead`k' = treat * (event_time == -`k')
}
forvalues k = 0/2 {
    generate byte lag`k' = treat * (event_time == `k')
}
xtset id year
xtreg y lead3 lead2 lag0 lag1 lag2 i.year, fe vce(cluster id)
test lead3 lead2
lincom lag0
list id year event_time lead3 lead2 lag0 lag1 lag2 in 1/6, noobs

    运行结果

    id 1 的 2014 年是基准期，所有 lead/lag 变量均为 0；对照组这些变量始终为 0。三个政策后系数接近模拟值 2，两个政策前系数接近 0，但不要求每次模拟给出固定 p 值。

    常见错误

    • 相对事件期为负时，不要把负号拼进变量名。
    • 不能把不显著的提前项写成“已经证明平行趋势”。
    • 所有相对时期都加入且不留基准，会产生共线性。

    动手练习

    如何验证基准期没有被误编码为政策当期？

    查看参考答案

    检查 year==2014 的 event_time 为 -1，并验证 lead3、lead2、lag0、lag1、lag2 在该年全为 0。year==2015 的处理组才有 lag0==1。
