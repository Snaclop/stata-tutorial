    _n、_N 与下标：编号和引用

    理解当前位置、组大小与固定编号的区别。

    基本语法参数与选项理解命令完整示例运行结果常见错误动手练习继续查帮助

    基本语法

    基本语法
    generate id=_n
generate nobs=_N
generate previous=x[_n-1]

    语法中的中文名称是占位说明；可直接执行的代码见下方完整示例。

    参数与选项

    参数 / 写法作用与使用条件写法示例
    _n当前范围内的观测位置，从1开始generate id=_n
    _N当前范围内的观测数display _N
    x[k]引用 x 的第 k 个位置x[1]
    x[_n-1]引用上一行的 x；越界返回缺失generate prev=x[_n-1]

    理解命令

    _n 不是一个已经保存的普通变量。把它赋给 id 后，id 就成为当时行序的快照；后续 sort 会让 id 跟着原记录移动，而不是重新编号。

    下标依赖当前顺序。第一行没有上一行，所以 x[_n-1] 在第一行是缺失。时间序列有缺口时，“上一行”也未必是“上一期”，后者应使用已声明时间变量的 L. 运算符。

    完整示例

    请在 do 文件编辑器中整段运行；示例会准备演示数据，请先保存当前数据。

    indexing.do
    sysuse auto, clear
generate int id = _n
sort price id
generate int price_rank = _n
generate int max_price = price[_N]
generate int previous_price = price[_n-1]
generate byte class = cond(_n <= _N/2, 1, 2)
label define tutorial_price_half 1 "低价一半" 2 "高价一半"
label values class tutorial_price_half
bysort class (price id): generate int groupid = _n
by class: generate int group_size = _N
tabulate class
list id make class price price_rank groupid group_size if groupid <= 3, sepby(class) noobs

    常见错误

    • 重新排序以后，保存的 id 不会自动变成新排名。
    • x[_N] 只有在排序和缺失处理正确时才可解释为最大值。

    动手练习

    生成 id=_n 后再排序，还能用 id 找回原始顺序吗？

    查看参考答案

    可以，只要 id 没被改写，sort id 即可恢复最初编号顺序。
