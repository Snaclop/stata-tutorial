    第 48 节

    随机数与 set seed：生成可复现的演示数据

    用随机函数构造练习数据，并控制随机序列的起点。

    基本语法参数与选项理解命令完整示例运行后看什么常见错误动手练习继续查帮助

    基本语法

    基本语法
    set seed 整数
generate double u = runiform()
generate int dice = runiformint(1, 6)
generate double z = rnormal(0, 1)

    语法中的中文名称是占位说明；可直接执行的代码见下方完整示例。

    参数与选项

    参数 / 写法作用与使用条件写法示例
    set obs #设置空数据集的观测数，为生成变量提供行。set obs 100
    set seed #设置随机种子；同一生成器与相同命令顺序下可重复序列。set seed 20261014
    runiform()生成 0 与 1 之间的均匀随机数。generate double u = runiform()
    runiformint(a,b)生成包含整数端点 a、b 的均匀随机整数。generate byte dice = runiformint(1,6)
    rnormal(mu,sigma)生成给定均值与标准差的正态随机数；sigma 不是方差。generate double z = rnormal(0,1)

    理解命令

    随机数适合创建不含真实个人信息的演示数据。先 set obs 确定行数，再生成随机变量。连续随机数建议显式使用 double，减少存储精度造成的舍入；随机整数可按范围选择 byte、int 或 long。

    set seed 指定序列起点，不保证任何一个小样本恰好满足理论均值或各组人数相等。要复现还需要相同的随机数生成器、命令顺序与数据行序；在循环中反复重设同一 seed 会重复产生相同序列。示例通过重新设种子验证序列可重现，而不把随机样本均值写成固定答案。

    完整示例

    请在 do 文件编辑器中整段运行；示例会准备演示数据，请先保存当前数据。

    random.do
    clear
set obs 10
set rng mt64
set seed 20261014
generate double u = runiform()
set seed 20261014
generate double u_again = runiform()
generate byte dice = runiformint(1, 6)
generate double z = rnormal(0, 1)
list, noobs

    运行后看什么

    u 与 u_again 逐行完全相同；dice 每个值都是 1 到 6 的整数。z 可以为正或负，10 行样本的均值无需正好为 0。

    常见错误

    • runiformint(1,6) 与 round(runiform()*5+1) 的分布不同；生成等概率整数直接用前者。
    • 不要把样本波动误认为命令错误；种子是可复现工具，不是改善样本代表性的工具。

    动手练习

    需要生成均值 100、标准差 15 的模拟分数，应使用什么函数？

    查看参考答案

    generate double score = rnormal(100,15)。正态分布本身无上下界，若要限制 0 到 100，应另行说明数据生成规则。
