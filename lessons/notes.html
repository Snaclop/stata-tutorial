    记录来源、单位和清洗依据，让数据脱离脚本后仍可理解。

    基本语法

    基本语法
    notes: 数据集备注
notes varname: 变量备注
notes list varname
notes replace varname in # : 新备注

    语法中的中文名称是占位说明；可直接执行的代码见下方完整示例。

    参数与选项

    参数 / 写法作用与使用条件写法示例
    notes: 文本给整个数据集添加备注，等同于对 _dta 记录备注。notes: 本数据为教学演示。
    notes 变量名: 文本给某一变量添加详细说明。notes score: 满分100，缺考记为数值缺失。
    notes / notes list列出全部备注或指定变量备注。notes list score
    notes replace ... in # :替换某条已编号备注。notes replace score in 1: 成绩单位为分。
    notes drop ... in #删除指定编号的备注。notes drop score in 2
    notes search 文本在数据及变量备注中查找关键词。notes search 单位

    理解命令

    变量标签适合简短标题；备注适合来源、统计口径、收集日期、缺失值规则和异常值修正依据。notes 将这些文字附着到数据或变量上，随 .dta 一起保存。它不参与计算，但能使之后使用数据的人理解某个值为什么被修改。

    脚本中的 * 注释 用于解释代码，备注用于解释数据；两者互补。每次添加备注会产生编号，修改时先运行 notes 查阅编号，再按编号替换。若只是补充信息，可新增一条；若错误说明已经失效，则应修改旧备注，避免留下互相矛盾的口径。

    完整示例

    请在 do 文件编辑器中整段运行；示例会准备演示数据，请先保存当前数据。

    示例会在当前目录生成 tutorial_notes.dta；再次运行可能覆盖这些同名演示文件。

    notes.do
    clear
input byte id double score
1 88
2 .
3 76
end
notes: 教学用模拟成绩数据。
notes score: 单位为分；数值缺失表示未参加考试。
notes score: 成绩允许范围为0到100。
notes list score
notes replace score in 2: 有效成绩范围为0到100，含端点。
save "tutorial_notes.dta", replace
clear
use "tutorial_notes.dta", clear
notes

    运行后看什么

    重读 DTA 后仍可看到数据集备注及 score 的两条备注；第 2 条已更新，score 的缺失值仍保留。

    常见错误

    • 备注不会随普通 CSV 完整保留；交换数据时应另提供数据字典或 DTA。
    • 备注不能代替实际数据修正；记录“单位已换算”之前必须确认代码确实完成了换算。

    动手练习

    应把“收入单位为元，缺失表示未回答”放在哪里？

    查看参考答案

    可用 label variable income "收入（元）" 作简短标题，再用 notes income: 单位为元；缺失表示未回答。记录详细规则。
