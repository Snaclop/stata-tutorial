    第 38 节

    egen rowmean：在同一行跨变量计算

    为每个观测计算多列均值、合计及缺失数量。

    基本语法参数与选项理解命令完整示例运行结果常见错误动手练习继续查帮助

    基本语法

    基本语法
    egen newvar = rowmean(varlist)
egen newvar = rowtotal(varlist) [, missing]
egen newvar = rownonmiss(varlist)
egen newvar = rowmiss(varlist)

    语法中的中文名称是占位说明；可直接执行的代码见下方完整示例。

    参数与选项

    参数 / 写法作用与使用条件写法示例
    rowmean(varlist)按行求非缺失值的平均数，全缺失时结果缺失。egen avg = rowmean(q1 q2 q3)
    rowtotal(varlist)按行求和，默认把缺失按 0 处理，包括全缺失行。egen total = rowtotal(q1 q2 q3)
    , missing配合 rowtotal：整行全部缺失时保留为缺失。egen total = rowtotal(q1 q2 q3), missing
    rownonmiss(varlist)统计每行非缺失变量的个数。egen answered = rownonmiss(q1 q2 q3)
    rowmiss(varlist)统计每行缺失变量的个数。egen unanswered = rowmiss(q1 q2 q3)
    rowmin() / rowmax()找出同一行多列中的最小或最大非缺失值。egen highest = rowmax(q1 q2 q3)

    理解命令

    纵向均值 egen mean(q1) 是不同观测在 q1 这一列上的平均；横向均值 egen rowmean(q1 q2 q3) 是同一个观测三项成绩的平均。变量列表可以写成 q1 q2 q3。如果使用 q1-q3，它指变量排列中从 q1 到 q3 的所有变量，不保证只有这三项，因此明确列名更稳妥。

    rowmean() 会自动减少缺失项目的分母，而 (q1+q2+q3)/3 只要任一项缺失就得到缺失。哪种方式合理取决于量表规则。若至少回答两项才可算平均，可先计算 rownonmiss()，再将回答不足两项的均值设为缺失。rowtotal(...), missing 只处理“全部缺失”，并不要求每一项都完整。

    完整示例

    请在 do 文件编辑器中整段运行；示例会准备演示数据，请先保存当前数据。

    egen-row.do
    sysuse auto, clear
* 用同一车型的价格构造两份教学报价，不混合不同单位。
generate double quote_low = price * .95
generate double quote_high = price * 1.05
replace quote_low = . if missing(rep78)
egen double price_mean = rowmean(price quote_low quote_high)
egen double price_min = rowmin(price quote_low quote_high)
egen double price_max = rowmax(price quote_low quote_high)
list make price quote_low quote_high price_mean price_min price_max in 1/5, noobs
list make price_mean if missing(quote_low), noobs

    常见错误

    • 不能把缺失自动视为得 0 分；rowtotal 默认行为不等于业务规则。
    • rowmean 已经跨列计算，不要再加 by 前缀；每行的变量本身就是所需计算范围。

    动手练习

    三项测量必须全部完成才计算均值，如何约束 rowmean 的结果？

    查看参考答案

    先 egen n_valid=rownonmiss(q1 q2 q3)，再 egen avg=rowmean(q1 q2 q3)，最后 replace avg=. if n_valid<3。
