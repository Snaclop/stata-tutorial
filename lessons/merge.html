    第 44 节

    merge：按键匹配数据

    通过编号等共同字段，把不同数据表的变量放到同一行。

    基本语法参数与选项理解命令完整示例运行结果常见错误动手练习继续查帮助

    基本语法

    基本语法
    merge 1:1 键变量 using "文件.dta", options
merge m:1 键变量 using "文件.dta", options

    语法中的中文名称是占位说明；可直接执行的代码见下方完整示例。

    参数与选项

    参数 / 写法作用与使用条件写法示例
    1:1 / m:1 / 1:m冒号左右分别表示内存主表与 using 表中键的唯一性。merge m:1 city using "city.dta"
    using filename要读入并匹配的 Stata 数据文件；不是 Excel 文件。using "city.dta"
    keepusing(varlist)只从 using 表引入所列非键变量。keepusing(region)
    generate(newvar)指定匹配状态变量名；默认是 _merge。generate(match_status)
    keep(master match)只保留主表独有与匹配成功的行。keep(master match)
    assert(match)要求所有匹配结果都为成功匹配，否则报错。assert(match)

    理解命令

    合并前先决定一行代表什么，再决定匹配键。个人表中同一城市可以出现多次，城市表中一个城市应只有一行，因此把城市属性并入个人表用 m:1 city。1:1 id 则要求两张表的 id 都唯一。可分别用 isid 检查需要唯一的一侧；不要为了让命令运行而随意删除键重复的记录。

    普通合并会留下状态变量：1 表示只在主表，2 表示只在 using 表，3 表示两边都找到。先检查状态，再决定是否筛选；一开始就用 nogen 或 keep(match) 容易掩盖未匹配记录。主表与 using 表存在同名非键变量时，默认以主表的值为准；应提前重命名、比较含义，而非默认认为两列会自动拼接。

    完整示例

    请在 do 文件编辑器中整段运行；示例会准备演示数据，请先保存当前数据。

    merge.do
    sysuse auto, clear
generate int auto_id = _n
tempfile attributes
preserve
keep auto_id foreign weight
drop if auto_id == 74
isid auto_id
save "`attributes'"
restore
keep auto_id make price
isid auto_id
merge 1:1 auto_id using "`attributes'"
tabulate _merge
list auto_id make price foreign weight _merge in 1/5, noobs
list auto_id make _merge if _merge != 3, noobs

    常见错误

    • 不要把 m:m 当作解决重复键的快捷方式；它通常不是期望的配对规则。
    • 键中的缺失值可能互相匹配；先检查缺失键、编码和空格。
    • keep() 筛选匹配结果，keepusing() 选择变量，两者作用不同。

    动手练习

    若只想保留成功匹配的观测，应如何操作？

    查看参考答案

    先检查 tabulate _merge；确认筛选符合分析目的后，执行 keep if _merge == 3。本例保留 73 条成功匹配的观测。
