    第 43 节

    collapse：把明细表汇总成分组表

    将多条明细记录转换为每组一行的统计结果。

    基本语法参数与选项理解命令完整示例运行后看什么常见错误动手练习继续查帮助

    基本语法

    基本语法
    collapse (mean) 新均值=变量 (sum) 新总和=变量 (count) 新计数=变量, by(分组变量)

    语法中的中文名称是占位说明；可直接执行的代码见下方完整示例。

    参数与选项

    参数 / 写法作用与使用条件写法示例
    (mean) / (sum) / (median)为后续变量指定统计量；不写统计量时默认为 mean。(mean) avg=score
    newvar=oldvar把统计结果命名为新变量，便于同时保存同一变量的不同统计量。(sum) total=score
    by(varlist)按这些变量的组合分组，每组形成一行；省略时全表汇总为一行。by(team)
    (count)统计指定变量的非缺失值数量，并非总行数。(count) n_valid=score
    cw要求参与汇总的各变量共同非缺失，改变有效样本口径。collapse (mean) x y, by(team) cw

    理解命令

    collapse 会直接替换内存中的数据：原来一行一个人的明细，变成一行一个团队的统计。只想在屏幕上看结果时用 summarize 或 tabstat；需要得到可继续合并、保存的汇总数据集时才用 collapse。若后面还要用明细数据，先 preserve。

    不同统计量可以对应同一原变量，但输出变量必须采用不同名字。默认对每个统计量分别排除相关缺失值，所以 count score 计的是成绩不缺失的人数。若需要每组原始总行数，可以先 generate byte one=1，再 (sum) n_rows=one。

    完整示例

    请在 do 文件编辑器中整段运行；示例会准备演示数据，请先保存当前数据。

    collapse.do
    clear
input str1 team int score
"A" 80
"A" 90
"B" 70
"B" .
end
generate byte one = 1
collapse (mean) mean_score=score (sum) total_score=score n_rows=one (count) n_valid=score, by(team)
list, noobs

    运行后看什么

    结果只剩 A、B 两行。A 的均值为 85、有效数为 2；B 的均值为 70、有效数为 1。两组原始行数 n_rows 都为 2。

    常见错误

    • collapse 后原明细不会留在内存；未保存也未 preserve 的修改无法通过 restore 恢复。
    • count 与总行数不同；数据缺失较多时尤其需要标明统计口径。

    动手练习

    如何同时得到每组成绩的均值和最大值？

    查看参考答案

    collapse (mean) avg=score (max) highest=score, by(team)
