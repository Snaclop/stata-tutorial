    基本语法

    基本语法
    twoway (scatter y x) (lfit y x), name(图名, replace)
histogram 变量, normal
graph box 变量, over(分组)
line y 时间, sort
graph export "图.png", name(图名) replace width(1200)

    语法中的中文名称是占位说明；可直接执行的代码见下方完整示例。

    参数与选项

    参数 / 写法作用与使用条件写法示例
    scatter / lfit先写纵轴、再写横轴；叠加线性拟合用于描述。twoway (scatter wage education) (lfit wage education)
    histogram, normal查看分布，并叠加正态密度作为参照。histogram wage, normal
    graph box, over()按组比较中位数、四分位和异常点。graph box wage, over(group)
    line ..., sort按横轴顺序连线；先明确一条线对应什么。line mean_wage year, sort
    name()保存多个命名图，导出时明确指定目标图。graph export "tutorial_hist.png", name(tutorial_hist) replace width(1200)

    理解命令

    散点图适合两个连续变量的关系，直方图适合一个连续变量的分布，箱线图适合分组比较，折线图适合有序时间序列。对同一份数据选择图形时，先确定读者需要比较什么。

    叠加 `lfit` 只展示线性拟合，不产生因果证据。直方图分箱数量会改变观感，正态曲线是参照而非“数据正态”的证明；箱线图中的异常点也不能直接作为删除规则。时间折线应先按时间排序，多个单位混在一起会连出无意义的线。

每张图使用独立名称，导出时写 `name()`，避免把当前最后一张图重复保存成多个文件。完整示例在后台生成图形，保存三张 PNG 后恢复原图形设置。图片配上清楚的标题与单位，输出文件均使用 tutorial_ 前缀。

    课件对照：Stata basic.pdf，第 14、17 页。

    完整示例

    请在 do 文件编辑器中整段运行；示例会准备演示数据，请先保存当前数据。

    示例会在当前目录生成 tutorial_fit.png、tutorial_hist.png、tutorial_box.png；再次运行可能覆盖这些同名演示文件。

    distributions.do
    sysuse auto, clear
local old_graphics "`c(graphics)'"
set graphics off
twoway (scatter price weight) (lfit price weight), ///
    title("Price and weight") xtitle("Weight (lbs.)") ///
    ytitle("Price (US dollars)") name(tutorial_fit, replace)
graph export "tutorial_fit.png", name(tutorial_fit) replace width(1200)
histogram price, normal title("Car price distribution") ///
    xtitle("Price (US dollars)") name(tutorial_hist, replace)
graph export "tutorial_hist.png", name(tutorial_hist) replace width(1200)
graph box price, over(foreign) title("Price by car origin") ///
    ytitle("Price (US dollars)") name(tutorial_box, replace)
graph export "tutorial_box.png", name(tutorial_box) replace width(1200)
set graphics `old_graphics'

    常见错误

    • graph export 不带 name() 时导出当前图，多图工作流容易选错。
    • 箱线图之外的点不必然是错误记录。
    • 折线图不能直接把不同人的同年数据串成一条线。

    动手练习

    把箱线图改为按 rep78 分组，应该修改哪里？

    查看参考答案

    将 over(foreign) 改为 over(rep78)，并检查 rep78 的缺失值以及每组样本量。
