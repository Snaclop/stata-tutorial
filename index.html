    共 15 个模块、63 节课程。初次学习，可以按顺序阅读；查找某条命令，可以展开顶部课程目录或使用搜索。每节都有语法、参数表、可运行示例和自测题。

    01开始使用

    • 认识 Stata 的工作流程分清数据、命令和结果，从一个最小分析开始。
    • pwd 与 cd：工作目录解决“文件明明存在，为什么找不到”的问题。
    • do 文件、注释与续行用注释与续行写清命令，按项目步骤组织可以重复执行的脚本。
    • log：记录分析过程让输出结果可保存、复查和分享。
    • help 与 which：查命令读懂官方帮助，比猜一个选项更可靠。
    • version / set：建立清楚的运行环境在脚本开头声明兼容行为，并管理输出、存储和随机设置。

    02命令与条件

    • 命令结构与变量列表准确区分命令主体、样本条件和选项。
    • if 与 in：选择观测按数值条件和当前位置筛选本次分析对象。
    • 缺失值与 missing()避免把缺失误当作高值、零或“否”。

    03文件与数据

    • use、sysuse 与 input选择适合本地文件和练习数据的读取方式。
    • import excel：读取 Excel 数据把指定工作表和单元格区域读入 Stata，并识别变量名与类型。
    • import delimited：读写 CSV 和文本表按分隔符读取文本数据，保留编号并处理表头和编码。
    • save 与 export：保存数据和交换文件区分保存 Stata 数据集与导出 Excel，并让结果可复现。

    04查看与统计

    • describe、list 与 count先确认结构和具体值，再开始汇总。
    • summarize：描述统计读懂有效样本量、均值、标准差与百分位数。
    • tabulate：频数和交叉表观察类别分布，并比较不同组中的计数。
    • tabstat：定制统计表选择统计量、分组方式与输出小数位。
    • correlate 与 pwcorr：看清相关系数和样本计算线性相关，区分共同完整样本与逐对完整样本。
    • return list 与 r()：读取结果把刚计算出的均值、计数或分位数用于下一步。

    05变量属性

    • rename 与 order：名字和列位置调整变量的名称与排列，不改动观测行。
    • 存储类型：byte、long、float 与 double根据取值范围与精度选择变量类型，并理解精度损失。
    • format：控制小数位和显示方式只改变显示外观，并区分格式、舍入与存储精度。
    • label：数据标签、变量标签和值标签用标签说明数据含义，同时保留适合计算的数值编码。
    • notes：把数据说明保存在数据集里记录来源、单位和清洗依据，让数据脱离脚本后仍可理解。

    06数据清理

    • destring 与 encode：两种字符串转换区分数字文本和类别文本，选择不会改变含义的转换方式。
    • 字符串清理与拼接处理空白、指定字符与英文大小写。
    • misstable 与 rowmiss：诊断缺失模式分别统计每列和每行的缺失，区分完整样本、部分缺失与整行缺失。
    • 异常值与缩尾：先核查，再决定处理用四分位距标记极端值，保留原变量并展示百分位缩尾的实现。
    • drop 与 keep：保留需要的数据区分删除变量列和删除观测行。
    • duplicates：发现重复并谨慎去重先确定重复的业务含义，再报告、标记或删除记录。
    • assert 与 isid：让数据规则可以检查把范围、唯一性和计算关系写成可重复执行的核对命令。

    07变量构造

    • generate 与 replace：创建和修改把逐行计算写成可追踪的命令。
    • 数学函数：对数、平方根和取整知道函数的定义域，也知道不同取整规则的区别。
    • cond、inlist 与 inrange用条件函数表达选择、集合和范围。
    • 虚拟变量：0/1 编码把类别信息写成可以解释的指示变量。
    • recode：按阈值划分类别把连续数值转换成有明确边界的分组。
    • egen：生成全样本与分组统计量把均值、总和与有效样本数变成变量，供后续计算使用。
    • egen rowmean：在同一行跨变量计算为每个观测计算多列均值、合计及缺失数量。
    • seq 与 fill：生成练习序列创建年份循环和分块编号，理解行顺序如何影响结果。
    • i. / c. / # / ##：理解因子变量写法用统一语法声明类别变量、连续变量和交互组合。

    08排序与分组

    • sort 与 gsort：排序明确升降序、多个排序键以及并列规则。
    • by 与 bysort：组内执行让同一条命令在每个组内分别运行。
    • _n、_N 与下标：编号和引用理解当前位置、组大小与固定编号的区别。

    09数据整合

    • merge：按键匹配数据通过编号等共同字段，把不同数据表的变量放到同一行。
    • append：把同结构数据纵向追加将另一批观测接到当前数据下面，并记录每行来自哪一批。
    • collapse：把明细表汇总成分组表将多条明细记录转换为每组一行的统计结果。
    • preserve / restore：临时修改后恢复暂存当前数据，在完成筛选或汇总后恢复到原状态。

    10自动化

    • local / global：用宏复用文字和参数将变量列表、阈值或路径文字存进宏，减少重复输入。
    • foreach / forvalues：重复执行一组命令对变量列表或连续数字重复相同操作。
    • 大样本：选择读取、压缩与可复现抽样按需保留变量，理解 sample 的百分比和固定数量两种模式。

    11回归分析

    • regress：OLS 回归与结果解读从单变量回归到多元模型，解释系数、标准误、置信区间和拟合优度。
    • 回归后：预测、检验与估计样本用 predict、test 和 lincom 回答模型估计之后的具体问题。
    • ivregress：工具变量与识别诊断用 2SLS 处理模拟内生性，检查第一阶段、内生性和过度识别限制。

    12政策评估

    • DID：处理组、对照组与政策前后用交互项和双向固定效应估计共同政策时点下的双重差分。
    • 事件研究：设定基准期与检查政策前趋势构造合法的相对时期变量，以政策前一年为基准做联合检验。
    • RDD：断点附近的局部比较中心化运行变量，允许断点两侧斜率不同，并检查带宽敏感性。

    13面板数据

    • xtset 与 xtreg：面板数据和固定效应检查个体与时间键，理解固定效应、随机效应和聚类标准误。

    14图形与扩展

    • tsset 与 L. / F. / D.：按时间取值声明时间索引后，按实际时间间隔计算滞后、超前与差分。
    • 随机数与 set seed：生成可复现的演示数据用随机函数构造练习数据，并控制随机序列的起点。
    • scatter / graph export：绘制并导出散点图用横纵坐标展示两个数值变量的关系，输出可用于网页或报告的图片。
    • twoway、直方图与箱线图：选择合适的图形叠加回归线、比较分布与组别，并把各张图单独导出。
    • which / ssc：检查与管理扩展命令区分自带命令与用户扩展，记录外部依赖并查找命令来源。

    15结果输出

    • estimates 与 putexcel：比较和导出回归结果保存多个模型，用统一表格比较，并把系数及标准误导出为 Excel。
